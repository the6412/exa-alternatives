## Working Code: Calling Geekflare in Minutes

Below are two minimal, runnable examples that demonstrate how to fetch a full Google SERP (including PAA) for the search term "exa alternatives". Adjust the `city` and `device` fields to match your target audience.

### Node.js / TypeScript SDK (`@geekflare/api-node`)

```ts
import { GeekflareClient } from '@geekflare/api-node';

const client = new GeekflareClient({
  apiKey: process.env.GEEKFLARE_API_KEY, // set your key in the env
});

async function fetchSerp() {
  const payload = {
    query: 'exa alternatives',
    serp: true,
    city: 'Austin,Texas,United States',
    device: 'desktop',
    output: 'json',
  };

  const response = await client.search(payload);
  console.log(JSON.stringify(response, null, 2));
}

fetchSerp().catch(console.error);
```

*What you get*: a JSON payload containing organic results, ads, the Google AI Overview, **People Also Ask** entries, local-pack data, and related searches—all for 2 credits.

### cURL Example

```bash
curl -X POST https://api.geekflare.com/search \
  -H "Content-Type: application/json" \
  -H "x-api-key: $GEEKFLARE_API_KEY" \
  -d '{
    "query": "exa alternatives",
    "serp": true,
    "city": "London,England,United Kingdom",
    "device": "mobile",
    "output": "json"
  }' | jq .
```

The response mirrors the SDK output. Replace `jq` with any JSON formatter you prefer. Both examples hit the same endpoint (`POST https://api.geekflare.com/search`) documented at `https://docs.geekflare.com/guides/search.md`.

## Why So Many Teams Outgrow Their First Scraping or Data API

1. **Hidden per-feature multipliers** – APIs that charge extra for each additional field (e.g., ads, local pack, PAA) quickly explode budgets once you need full SERP context.
2. **Credit rollover expectations** – Teams assume unused credits roll over; when they don't, month-end overruns force emergency upgrades.
3. **Rate-limit throttling** – Low req/s limits cause queue backlogs in CI pipelines, leading to missed data windows.
4. **Fragmented tooling** – Maintaining separate keys for search, screenshot, and PDF generation creates operational overhead and sync bugs.
5. **Unclear refund policies** – Without a money-back guarantee, teams hesitate to experiment, resulting in over-provisioned plans.

Geekflare addresses each of these pain points with flat credit costs, clear rules, tiered req/s that match most production needs, a single-key ecosystem, and a 7-day refund guarantee.

## Frequently Asked Questions

1. **What happens if I exceed my monthly credit limit?**  
   Requests stop at 100% consumption. You receive an email at 90% usage and can either upgrade the plan or add a one-time credit pack to resume traffic.

2. **Can I use a rotating proxy on the Free tier?**  
   No. Proxy access (+4 credits) is only available on paid tiers (Starter and above). The Free tier provides direct IP access without proxy rotation.

3. **Is the Google AI Overview included in the standard SERP call?**  
   Yes. When you set `serp:true`, the response contains `data.ai_overview` with text, HTML, and cited sources—all for the same 2-credit cost.

4. **Do failed 5xx responses consume credits?**  
   No. Any server error or failed capture is free, preserving your credit balance for successful calls.

5. **How do I monitor credit consumption in real time?**  
   The dashboard shows a live credit counter and sends a webhook when you cross 90% usage. You can also query the usage endpoint via the API for programmatic alerts.
